# Школа Терапии — практические работы по стартапу

Учебный репозиторий по дисциплине «Стартап в информационных технологиях».

**Стартап:** «Школа Терапии»

**Формат:** онлайн-школа для студентов-медиков, ординаторов и молодых врачей

**Идея:** подготовка к экзаменам и аккредитации через клиническую логику, практику и поддерживающую образовательную среду.
