# Стартап в информационных технологиях

## Школа Терапии

**Работа:** третья неделя

**Тема:** опубликованный лендинг и подключение Яндекс Метрики

## Задача работы

Представить опубликованный продающий сайт: выбор платформы, структуру, содержание, фирменное оформление и целевое действие. Дополнительно описать подключённую Яндекс Метрику и вывод статистики в админку школы.

## Выбор платформы

Для публичного лендинга используется кодовая реализация на HTML, CSS и JavaScript с собственным доменом. Такой подход позволяет управлять структурой страницы и сохранять фирменное оформление. Для университетской работы используется уже существующий сайт школы.

Платформа с кабинетом и админкой развивается отдельно на Next.js. Разделение позволяет показывать маркетинговый сайт и описывать возможности беты без смешения их статусов.

## Опубликованный лендинг

[Открыть публичный сайт «Школы Терапии»](https://school-drtamuna.ru/)

**Главный экран:** «Думать как врач. Учиться без страха».

**Целевая аудитория:** студенты-медики, ординаторы и молодые врачи.

**УТП:** системная подготовка через клиническую логику, практику и поддерживающую атмосферу.

| Блок | Содержание и назначение |

| Преподаватели | Представление практикующих врачей и их направлений |

Страница содержит больше пяти ключевых блоков, требуемых заданием.

## Целевое действие — CTA

**Основной CTA:** «Написать в Direct» — переход к [аккаунту школы](https://www.instagram.com/school.of.therapy/).

**Дополнительный CTA:** «Задать вопрос» и «Заказать пособие» — переход в [Telegram школы](https://t.me/schooltherapy).

Путь посетителя: знакомство с предложением, выбор интересующего формата, переход к общению со школой. Для лендинга целевым действием служит переход по ссылке. Сам переход не подтверждает отправку сообщения или покупку.

## Фирменное оформление и мобильная версия

На сайте используются сливовые и светлые тёплые оттенки, крупные заголовки и спокойная типографика. Оформление согласуется с брендбуком первой недели.

В разметке предусмотрены настройки мобильного viewport и адаптивные стили. При проверке в браузере на ширине 390 пикселей главный экран перестроился в одну колонку, кнопка обращения осталась видимой, горизонтального переполнения страницы не обнаружено. Это проверка мобильного размера в браузере; результат на физическом телефоне отдельно не заявляется.

## Дополнительное задание: Яндекс Метрика

Яндекс Метрика подключена к бета-версии платформы. В защищённой [админке школы](https://beta.schooloftherapy.ru/admin) размещён компактный блок статистики.

| Возможность | Реализованный результат |
|---|---|
| Получение данных | Сервер читает агрегированные отчёты Яндекс Метрики |
| Показатели | Посетители, визиты и просмотры |
| Периоды | Сегодня, 7 дней и 30 дней |
| Управление | Выбор периода и обновление статистики |
| Фоновое обновление | Получение отчётов запускается каждые пять минут |
| Доступ | Панель и настройки доступны авторизованным сотрудникам |
| Ошибки | Отдельно показаны отсутствие подключения, ошибка доступа и временная недоступность |

Доступ к API настроен для чтения. Секрет подключения хранится защищённо на сервере и не включается в учебные материалы.

Статистика помогает оценивать посещаемость платформы и интерес к сайту. Для оценки продаж нужны отдельные данные о заявках и оплатах. Наличие трёх показателей в админке само по себе не означает настройку целей, Вебвизора или полной сквозной аналитики.

Проверка отчётов относится к приёмке 09.10.2026. Новое обращение к закрытой серверной статистике 13.10.2026 в рамках учебной работы не выполнялось. Публичный лендинг и бета используют разные адреса: подключение Метрики в бете не переносится автоматически на старый лендинг.
